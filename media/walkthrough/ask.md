# Ask in plain English

Open the chat and ask anything about the database:

- What is the orders table for?
- How do payments connect to products?
- Write a query for the top five customers by total spend.
- Paste a query to have it explained step by step.

When the answer contains SQL, you get a **Run** button. Nothing runs until you press it. Queries are SELECT only, run in a read-only transaction, return at most 100 rows and stop after 15 seconds.

After a query runs, the AI does not see the rows. Press **Let the AI see these rows** if you want an explanation of them. A few rows are sent, with sensitive-looking columns hidden.
